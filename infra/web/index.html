Modifier une entrée écrit registry.yaml, rien de plus. Lancer Claude demande explicitement un run (claude -p + skills du projet) ; le runner les exécute un par un. Le point : vert = conforme au dernier run réussi, orange = modifié depuis le dernier run, rouge = dernier run en échec ou bloqué (statut déclaré par Claude via le tool run_report), bleu = run demandé / en cours.

Historique

Chronologie : chaque version de l'entrée du registre et chaque run de Claude. Clique sur un run pour voir le prompt, le résumé et le déroulé complet (appels d'outils inclus).

Discussion

Reprend la session Claude de ce run, avec tout son historique (ce qu'il a lu, lancé, constaté). La discussion part d'une copie : le déroulé du run n'est pas modifié. Chaque message recharge tout l'historique : un message peut coûter quelques dizaines de centimes.

Projet

Les secrets ne se saisissent pas ici : infra secrets edit projects/<nom>.env (sops). Minimum : repo + expose. Le comment (container, port, fichier compose, build…) n'est pas à toi : Claude le détermine au run et l'écrit dans le registre.
